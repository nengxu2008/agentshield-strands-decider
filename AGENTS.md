# For AI coding assistants

This repository is the AWS User Group Madurai Strands Decider hackathon kit. Read these first:
- `.kiro/steering/hackathon.md`: the rules and the honesty and originality constraints.
- `.kiro/steering/kit.md`: the layout and contracts.
- `.kiro/steering/decider.md`: how to write Strands Decider questions.

The workflows are in `.kiro/skills/*/SKILL.md`; start with `hackathon`. Change `agent/`, keep
the contracts, never commit `.env`, and keep the kit credit line.
